プレビュー

作成には Anthropic の Claude Code を用いました。β版のため、画面や出力は予告なく変わることがあります。書き出したスタイルは、最後に Zotero などで確かめてください。

読み込んだ書誌（CSL JSON）や .csl は、このブラウザの中だけで処理します。外部には送信しません。作業中の状態は、このブラウザの中に保存されます（ほかの人やほかの端末からは見えません）。

このアプリは AGPL-3.0 で公開しています（ソース）。組版エンジン citeproc-js（CPAL 1.0 または AGPL 3.0）と、CSL のロケール（CC BY-SA 3.0）を同梱しています。詳しくは「使い方」をご覧ください。

不具合の報告やご意見は、GitHub の Issues へお寄せください。

引用スタイルを選ぶ

公式のスタイルを手直しする

Zotero のスタイル一覧から使いたいスタイル（Chicago など）の .csl をダウンロードし、ここに落とすか、ボタンで選んでください。出力を見ながら、気になる所を直せます。前にこのアプリで書き出した .csl も、続きから直せます。

ファイルはこのブラウザの中で読むだけで、どこにも送られません。

型から組む（和文の書式も作れる）

書きたい形に近いスタイルを選んでください。選んだスタイルをもとに、部品を並べ替えて自分の使いたいスタイルに編集できます。

各スタイルの典型的な形を簡略に再現した出発点です。公式のスタイルではなく、各団体とは関係ありません。規定どおりかは、それぞれの規定で確かめてください。

見本は、見本データの欧文と和文の本を、それぞれの書き方で組んだものです。

どちらを選んでも、いまの編集は置き換わります。

見本の書誌を編集する

Zotero から自分の文献を取り込む

  1. Zotero で使いたい文献を選び（Ctrl か ⌘ を押しながらで複数）、右クリックして「選択された項目をエクスポート...」を選びます。
  2. 形式で「CSL JSON」を選んで保存します。文献のデータを、書式を付けずにそのまま書き出す形式で、Zotero が引用を組むときに使うのと同じ形です。
  3. 下の「ファイルを選ぶ」で、保存したファイル（.json）を選びます。

選んだあと、いまの文献と置き換えるか、足すかを選べます。ファイルはこのブラウザの中で読むだけで、どこにも送られません。

言語ごとの見本を足す

押した言語の見本（図書・本の章・雑誌論文・ウェブページの4件）が、いまの文献に加わります。もう一度押すと外れます。架空の文献です。その言語の書式を足すと、その形で組まれます。

文献を選んで直す

チェックを外した文献は、プレビューに出しません（データは残ります）。題名を押すと直せます。直した内容はこのブラウザの中にだけ保存され、Zotero のデータは変わりません。

言語別に書き出す

書式ごとに、別々のスタイル（.csl）を作ります。pandoc など、言語による書き分けに対応しないソフトでも使えます。ただし1つのスタイルはすべての文献をその書式で組むので、和文と欧文が混ざった文献リストには「多言語版」を使ってください。Zotero では、多言語版でも和文と欧文を書き分けられます。

引用スタイル（CSL）編集アプリ

このアプリは、Zotero で日本語に対応した CSL を編集するのをサポートするためのアプリです。

使い方

詳しい操作方法は、使い方のページをご覧ください。

このアプリでは、公式のスタイルを手直しする方法と、アプリが用意した引用スタイルから自分の引用スタイルに調整する方法の2種類が使えます。

  1. 土台にする引用スタイルを選ぶ
    公式のスタイルを手直しする

    Zotero のスタイル一覧からダウンロードした .csl を、最初の画面でアップロードします。前にこのアプリで書き出した .csl も、続きから直せます。

    アプリが用意した引用スタイルから始める

    Chicago 風・APA 風・MLA 風・IEEE 風から、書きたい形に近いものを選びます。各スタイルの典型的な形を簡略に再現した出発点です。公式のスタイルではなく、各団体とは関係ありません。規定どおりかは、それぞれの規定で確かめてください。

    最初の画面は、あとから「引用スタイルを選び直す」かアプリ名を押すことで、また開きます。ただしそれまでの編集は破棄されるため、後から復元したい場合は一度書き出してください。書き出した .csl は、最初の画面でアップロードすると続きから直せます。

  2. 右のプレビュー画面を見ながら、好みのスタイルに整える
    部品を並べる

    左の「和文の書式」「欧文の書式」で、資料の種類ごとに部品（チップ）を並べます。チップはドラッグか ← → で動かせます。押すと、括弧や前後の文字を変えられます。

    資料の種類は、図書・本の章・雑誌論文・ウェブページが既定です。学位論文や新聞記事などを別の並びで組みたいときは、「項目の種類を選ぶ」でチェックを入れます。チェックの無い種類は「その他」の並びで組みます。

    区切りを足す・引く

    チップの間には区切り（、 , . など）を置きます。区切りは、すぐ後ろの部品とひと組で、チップの列でも後ろの部品にくっついて表示されます。後ろの部品が空の文献では、区切りも一緒に消えます。行の頭（〔 の直後を含む）には出ません。たとえば「書名 ．出版者 ，年」で出版者が空なら「書名，年」になります。

    まとめる

    「〔 〕で囲む」で部品をまとめると、中が全部空の文献では、まとまりごと消えます。たとえば「書名. 〔訳者, 出版者, 年〕」とまとめれば、訳者のいない本でも「書名. 出版者, 年」になります。括弧（ ）は、まとまりの前後に付けると、中身が無いときに空の括弧が残りません。Zotero の公開スタイルも、同じ仕組み（CSL の group）で空欄を処理しています。

    公式のスタイルを手直ししているとき（微調整・大幅修正）

    左の上で「微調整」と「大幅修正」を選べます。

    微調整では、元のスタイルの書き方にそのまま手を入れます。右のプレビューで直したい箇所を押すと、その部品と、同じ部品から出ている所がすべて光り、左で前後の文字・区切り・斜体などを直したり、出さないようにしたり、隣の部品と入れ替えたりできます。手を入れた箇所は一覧になり、1件ずつ元に戻せます。

    大幅修正では、元のスタイルを部品（チップ）に移し、「部品を並べる」と同じように、資料の種類ごとに部品を足したり並べ替えたりできます。和文の書式も入るので、多言語版を作れます。元のスタイルと出力が違う見本は、上の帯に一覧で出ます。元のスタイルの手を入れていない部分は、そのまま残ります。

    自分の文献で確かめる

    プレビューの「見本の書誌を編集する」から、Zotero の文献を取り込めます。Zotero で文献を選んで右クリック →「選択された項目をエクスポート...」→ 形式「CSL JSON」で保存したファイルを選ぶと、自分の文献でプレビューできます。読み込まなければ見本データで練習できます。

    同じ画面で文献を選んで直すことも、新しく入れることもできます。各文献の「直す」でも書き換えられます。「隠す」はその文献をプレビューに出さないだけで、データは残ります（プレビューの下の「隠した文献」から戻せます）。「参考文献を作成」でコピーした文章は使えません（整形済みの文字なので、組み直せないため）。

  3. 引用スタイルのタイトルを調整する

    .csl のファイル名ではなく、上の「スタイル名」に入力された名前が、引用スタイルの名前として使われます。

    付けられる名前と、読み込んだスタイルの名前

    スタイル名は半角の英字・数字と _ - . ( ) と空白で付けます（日本語は使えません）。型から始めたときのスタイル名は My_Chicago_style のようになります。

    前に書き出した .csl を読み込むと、ファイル名に _edited を付けた名前になり、ID も新しくなります（Zotero では元のスタイルと別に入ります）。_edited の付いたものをもう一度読み込んで直したときは、名前も ID もそのままなので、Zotero では同じスタイルの更新になります。

  4. 多言語版で書き出し、Zotero の 設定 → 引用 → スタイル → ファイルから追加する
    多言語版と、言語別に書き出す場合

    多言語版は、和文と欧文を1つのスタイルで書き分けます。Zotero でも、文献の「言語」欄に ja や en が入っていれば、そのまま書き分けます（入れるときに確認の画面が出る場合があります。OK で入れられます）。

    言語による書き分けに対応しないソフト（pandoc など）で使うときは「言語別に書き出す」で、書式ごとのスタイルを作ります（2つ以上選ぶと zip にまとめます）。

もっと詳しく

和文と欧文

どちらの書式で組むかは、Zotero の「言語」欄で決まります。ja なら和文、en fr de などなら欧文です。欄が空の文献は和文の書式で組みます。プレビューに警告が出たら、Zotero で言語欄を直してください。

多言語版は、Zotero（Word・Google ドキュメントのプラグイン）でも、LaTeX の citation-style-language パッケージ（citeproc-lua）でも、言語欄に従って書き分けます。pandoc は言語による書き分けを読めないので、「言語別に書き出す」で作ったスタイルを使います。

英語は「欧文の書式」が既定です。言語ごとに変えたいときは、「＋ 言語ごとの書式」で言語を選んで足します。中国語（大陸式・台湾式）・韓国語・ロシア語・フランス語・ドイツ語・アラビア語・イタリア語・スペイン語・トルコ語は、その言語の人文学の論文で一般的な書き方が既定になります。一覧にない言語は、言語コード（pl など）を入れて足せます（欧文の書式を写します）。その言語の文献だけが、足した書式で組まれます。

2回目以降の注

注形式では、「注（2回目以降）」と「注（直前と同じ文書）」の並びを別に作れます。間に別の注を挟んで同じ文書を引くと短縮形（山本『デジタル史料学入門』50頁）、直前の注と同じ文書なら「同上」（頁も同じなら「同上。」、頁が違えば「同上、45頁。」）になります。短縮形の題名には Zotero の「短いタイトル」欄が使われます。書き分けは「全体の設定」で切れます。

縦書きで使う（数字を漢数字にする）

プレビューの上の「横書き／縦書き」で、組み上がりを縦書きで見られます。操作は横書きと同じです。「縦中横で見る」は、Word で2桁の数字を縦中横にしたときの見え方を確かめるためのものです。縦中横は CSL では指定できない（斜体・太字・下線などしか持てない）ので、スタイルには入りません。Word の側で設定してください。

「和文の書式」の「和文の書式全体」で「数字」を漢数字にすると、巻・号・頁・版・引用箇所が「四二頁」「二三〇頁」（〇を使う）か「四十二頁」「二百三十頁」（十百千を使う）になります。Zotero のデータは算用数字のままでかまいません。

発行年は漢数字にできません。Zotero（の組版エンジン）が、年を漢数字で組む機能を持たないためです。4桁かどうかや、元号かどうかとは関係ありません。年は、提出前に文書の側で直してください。

和暦で出したいときは、Zotero の日付欄に「平成八」のように「年」を付けずに入れてください。Zotero は和暦を年として読めないので、入れた文字のまま渡し、書式が「年」を付けて「平成八年」になります。「平成八年」と入れると「平成八年年」と重なります（プレビューに警告が出ます）。和暦で入れた文献は、年の順の並べ替えと、著者年形式の 2024a・2024b の書き分けには使われません。

CSL の仕様にない用語の使い方で実現しているので、Zotero（Word・Google ドキュメントのプラグイン）では効きますが、pandoc などほかのソフトでは算用数字に戻ります。3000 を超える数字も算用数字のままです。

五十音順に並べる

Zotero には読みの欄がないので、「その他（Extra）」欄で代用します。和文の文献の Extra 欄の1行目に、著者の読みをひらがなで入れ（例：やまもと はなこ）、「全体の設定」の「参考文献の並び」で「読みで五十音順に並べる」を選びます。Extra 欄は、組版エンジンには CSL の note として渡ります。

  • 読みのない和文の文献は、読みのある文献の後ろに、著者名の文字コード順で並びます。プレビューに警告が出ます。
  • Extra 欄の1行目に別の文字（Citation Key: … など）があると、その文字で並びます。original-date: 1990 のような CSL の変数の行は、先にあっても飛ばされます。
  • 欧文の文献は、Extra 欄を見ずに著者名で並べます。
  • 並び順は、プレビューの下の「参考文献の並び順を見る」で確かめられます。
