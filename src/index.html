プレビュー

引用スタイル（CSL）編集アプリ（β版）　版 （2026年、Ayano KOKAZE 作成）。作成には Anthropic の Claude Code を用いました。β版のため、画面や出力は予告なく変わることがあります。書き出したスタイルは、最後に Zotero などで確かめてください。

読み込んだ書誌（CSL JSON）や .csl は、このブラウザの中だけで処理します。外部には送信しません。作業中の状態は、このブラウザの中に保存されます（ほかの人やほかの端末からは見えません）。

このアプリは AGPL-3.0 で公開しています（ソース）。組版エンジン citeproc-js（CPAL 1.0 または AGPL 3.0）と、CSL のロケール（CC BY-SA 3.0）を同梱しています。詳しくは「使い方」をご覧ください。

引用スタイルを選ぶ

公式のスタイルを手直しする

Zotero のスタイル一覧から使いたいスタイル（Chicago など）の .csl をダウンロードし、ここに落とすか、ボタンで選んでください。出力を見ながら、気になる所を直せます。前にこのアプリで書き出した .csl も、続きから直せます。

ファイルはこのブラウザの中で読むだけで、どこにも送られません。

型から組む（和文の書式も作れる）

書きたい形に近いスタイルを選んでください。選んだスタイルをもとに、部品を並べ替えて自分の使いたいスタイルに編集できます。

各スタイルの典型的な形を簡略に再現した出発点です。公式のスタイルではなく、各団体とは関係ありません。規定どおりかは、それぞれの規定で確かめてください。

見本は、見本データの欧文と和文の本を、それぞれの書き方で組んだものです。

どちらを選んでも、いまの編集は置き換わります。

見本の書誌を編集する

Zotero から自分の文献を取り込む

  1. Zotero で使いたい文献を選び（Ctrl か ⌘ を押しながらで複数）、右クリックして「選択された項目をエクスポート...」を選びます。
  2. 形式で「CSL JSON」を選んで保存します。文献のデータを、書式を付けずにそのまま書き出す形式で、Zotero が引用を組むときに使うのと同じ形です。
  3. 下の「ファイルを選ぶ」で、保存したファイル（.json）を選びます。

いまの文献と入れ替わります。ファイルはこのブラウザの中で読むだけで、どこにも送られません。

文献を選んで直す

自分の分野の書誌に近づけると、プレビューでそのまま確かめられます。直した内容はこのブラウザの中にだけ保存され、Zotero のデータは変わりません。

言語別に書き出す

書式ごとに、別々のスタイル（.csl）を作ります。pandoc など、言語による書き分けに対応しないソフトでも使えます。ただし1つのスタイルはすべての文献をその書式で組むので、和文と欧文が混ざった文献リストには「多言語版」を使ってください。Zotero に入れるときの警告は出ません。

使い方

  1. 公式のスタイルを手直しする：Zotero のスタイル一覧からダウンロードした .csl を、最初の画面でアップロードします。右のプレビューで直したい箇所を押すと、その部品と、同じ部品から出ている所がすべて光り、左で前後の文字・区切り・斜体などを直したり、出さないようにしたり、隣の部品と入れ替えたりできます。直すと影響する範囲（参考文献と注の両方など）も左に出ます。手を入れた箇所は一覧になり、1件ずつ元に戻せます。元のスタイルの手を入れていない部分は、そのまま残ります。
  2. 引用スタイルを選ぶ：最初に開く画面です（あとから「引用スタイルを選び直す」かアプリ名を押すと、また開きます。いまの編集は置き換わります）。Chicago 風・APA 風・MLA 風・IEEE 風から、書きたい形に近いものを選びます。各スタイルの典型的な形を簡略に再現した出発点です。公式のスタイルではなく、各団体とは関係ありません。規定どおりかは、それぞれの規定で確かめてください。前に書き出した .csl があれば、それを読み込んで続きから直せます。
  3. 自分の文献で試す：プレビューの「見本の書誌を編集する」から、Zotero の文献を取り込めます。Zotero で文献を選んで右クリック →「選択された項目をエクスポート...」→ 形式「CSL JSON」で保存したファイルを選ぶと、自分の文献でプレビューできます。読み込まなければ見本データで練習できます。プレビューの「見本の書誌を編集する」で文献を選んで直すことも、新しく入れることもできます。各文献の「直す」でも書き換えられます。「隠す」はその文献をプレビューに出さないだけで、データは残ります（プレビューの下の「隠した文献」から戻せます）。「参考文献を作成」でコピーした文章は使えません（整形済みの文字なので、組み直せないため）。
  4. 部品を並べる：左の「和文の書式」「欧文の書式」で、資料の種類ごとに部品（チップ）を並べます。チップはドラッグか ← → で動かせます。押すと、括弧や前後の文字を変えられます。資料の種類は、図書・本の章・雑誌論文・ウェブページが既定です。学位論文や新聞記事などを別の並びで組みたいときは、「項目の種類を選ぶ」でチェックを入れます。チェックの無い種類は「その他」の並びで組みます。
  5. 区切り：チップの間には区切り（、 , . など）を置きます。区切りは両側に部品があるときだけ出ます。部品が空の文献では、その部品と、その前の区切りが消えます。
  6. まとめる：「〔 〕で囲む」で部品をまとめると、中が全部空の文献では、まとまりごと消えます。たとえば「書名. 〔訳者, 出版者, 年〕」とまとめれば、訳者のいない本でも「書名. 出版者, 年」になります。括弧（ ）は、まとまりの前後に付けると、中身が無いときに空の括弧が残りません。Zotero の公開スタイルも、同じ仕組み（CSL の group）で空欄を処理しています。
  7. 書き出す：スタイル名は半角の英字・数字と _ - . ( ) と空白で付けます（日本語は使えません）。型から始めたときのスタイル名は My_Chicago_style のようになります。前に書き出した .csl を読み込むと、ファイル名に _edited を付けた名前になり、ID も新しくなります（Zotero では元のスタイルと別に入ります。_edited の付いたものをもう一度読み込んで直したときは、名前も ID もそのままなので、Zotero では同じスタイルの更新になります）。ふつうは「多言語版を書き出す」で、和文と欧文を1つのスタイルで書き分けます（Zotero では入れるときに警告が出ます）。言語による書き分けに対応しないソフト（pandoc など）で使うときは「言語別に書き出す」で、書式ごとのスタイルを作ります（2つ以上選ぶと zip にまとめます）。保存したら、Zotero の 設定 → 引用 →「＋」から入れます。

和文と欧文

どちらの書式で組むかは、Zotero の「言語」欄で決まります。ja なら和文、en fr de などなら欧文です。欄が空の文献は和文の書式で組みます。プレビューに警告が出たら、Zotero で言語欄を直してください。

英語は「欧文の書式」が既定です。フランス語の文献は « » や「et」で組みたい、など言語ごとに変えたいときは、「＋ 言語ごとの書式」から言語コード（fr de など）を入れて足します。その言語の文献だけが、足した書式で組まれます。

2回目以降の注

注形式では、「注（2回目以降）」と「注（直前と同じ本）」の並びを別に作れます。間に別の注を挟んで同じ本を引くと短縮形（山田『デジタル史料学入門』50頁）、直前の注と同じ本なら「同上」（頁も同じなら「同上。」、頁が違えば「同上、45頁。」）になります。短縮形の題名には Zotero の「短いタイトル」欄が使われます。書き分けは「全体の設定」で切れます。

CSL ではできないこと

  • 五十音順に並べること：Zotero には読みの欄がありません。並びは漢字の文字コード順になります（読みを持てる Jurism という派生版もあります）。
